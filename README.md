# Keelson skills

Agent skills for deploying and operating web apps on [Keelson](https://keelson.dev).

This repository is generated from the skill embedded in each Keelson CLI release.
Do not edit it directly or send pull requests; changes are made in the private
Keelson source repository and mirrored here mechanically.

Install the Keelson CLI before using the skill. See the
[Keelson documentation](https://keelson.dev/docs/) for installation and usage.

Use only one installation method for the skill: either your AI tool's plugin
manager or `keelson install-agent`.
